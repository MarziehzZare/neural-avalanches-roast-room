# Council report contract

Use the actual selected mode and actual completed rounds. This is an output structure, not a pre-filled conclusion. Keep short consultations short; expand only when the research question needs it.

## Header and scope

- Review question, precise claims and system/modality/preparation.
- Mode: FULL / QUICK / NAMED / CONSULT; all included names and rounds completed.
- Simulation disclosure: “Simulated lens grounded in selected published work; not this person’s participation, endorsement, current opinion or predicted advice.”
- Execution disclosure: separate temporary read-only model tasks or single-model sequential lenses; do not misstate independence. State that this is not real peer review.

## Bottom line

Lead with the narrow defensible conclusion, strongest caveat and next discriminating test. If information is missing, say what inference is unavailable rather than fabricate a verdict. Separate the observation from its proposed mechanism and causal function. Do not reduce the result to who won the debate.

## Claim/evidence ledger

For every proposition list: claim ID; claim and scope; supplied observation versus interpretation; evidence type/access/version; exact source URL placed on the supported claim; qualitative status with reason; strongest alternative; boundary of generalization. An authorized private-file reference must remain within its permitted audience, not be copied into a public citation/search. No truth percentages, averaged expert judgments or majority proof.

## Round record and real cruxes

Use one row or short section per included named lens: opening disposition; challenged/conceded argument; final disposition and what changed; final uncertainty; exact relevant citations. Preserve frozen cards in full if material to the requested report, otherwise give faithful compact summaries and offer the full record within the authorized context. Include ratification/amendment/dissent per seat in FULL/NAMED; state “two rounds; no separate ratification” in QUICK. Never fabricate unavailable child responses.

Explain 1–3 evidential cruxes, including distinct predictions and any disagreement that remains. If unanimous, include the strongest alternative considered and why consensus adds no independent experimental evidence. Coauthored papers and repeated use of a dataset are not independent replications.

## Test and decision table

For each high-priority test list: target inference; strongest competing model; required authorized data; proposed analysis/design; expected discriminating outcome; confound and robustness checks; criterion for abandoning/revising that inference; uncertainty and prerequisites. Mark everything unrun as proposed. Prefer the smallest informative test, not maximal data collection by default. Never imply animal/human experiments, data downloads or training have been authorized or performed.

If explicitly requested, add a separate “Subjective design utility” table using preregistered criteria, weights, anchored scores and shown arithmetic. Keep it apart from the scientific ledger; never call it confidence or probability of truth.

## Limitations and close

Record access gaps, selected-corpus limits, measurement/model mismatch, scope of generalization and the evidence that would materially change the call. End with the strongest dissent and a concrete next step. No automatic monitoring, external messages, resource creation or follow-up execution.
